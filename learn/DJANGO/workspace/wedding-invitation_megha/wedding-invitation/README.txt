KAVIN & MEGHA - WEDDING INVITATION WEBSITE
==========================================
Open index.html in any browser (or upload the whole folder to any web host / GitHub Pages / Netlify).

Structure
  index.html
  style.css
  script.js          <- change names, date, venue, links at the top (the "wedding" object)
  images/            hero.jpg, story.jpg, gallery-1..4.jpg  (sample images - replace with real photos, keep the same names)
  audio/music.mp3    sample background music - replace with your own song, keep the same name

Notes
  - Internet is needed for the Google Fonts and the Google Map.
  - To receive RSVPs on WhatsApp, set whatsappNumber in script.js (e.g. "919876543210").
  - The countdown targets Nov 12, 2026, 5:00 PM IST.
