improvements for HAC project:



🔐 First priority: Authentication

This is where I'd start.

Your current system has:

Frontend
   ↓
localStorage
   ↓
"role = super_admin"

That's not acceptable for actual deployment.

Instead:

User
 ↓
POST /api/auth/login
 ↓
Backend
 ↓
Verify email
 ↓
Verify password
 ↓
Check account status
 ↓
Check role
 ↓
Generate access token
 ↓
React

Then every protected API request becomes:

Authorization: Bearer <token>

Backend verifies it.










👑 Super Admin should be created differently

We should not have:

User selects Super Admin
        ↓
Frontend says "I'm Super Admin"

Instead:

Database
   │
   └── users
          │
          ├── role = SUPER_ADMIN
          ├── role = ADMIN
          ├── role = WARDEN
          ├── role = MESS_MANAGER
          └── role = STUDENT

Only an existing authorized administrator should be able to create another administrator.

For the first Super Admin, we'll create it using a secure backend initialization command.

Something like:

python -m app.create_admin

That creates:

email
password hash
role = SUPER_ADMIN
status = ACTIVE

No public Super Admin registration.
